# Digital QR Menu

A modern, mobile-friendly digital menu for hotels and cafes that replaces traditional paper menus. Customers can easily view the menu by scanning a QR code at their table — no printing, no manual updates, and no hassle.  

## Features

- Mobile-first design optimized for QR scanning  
- Clean, attractive user interface  
- Manual language toggle: English / Amharic  
- Categories for Food, Drinks, Fruits, Coffee  
- Menu item cards with images, description, price, and stock status  
- Smooth scroll and sticky navigation for easy browsing  

## Benefits

- Eliminates the cost and inconvenience of paper menus  
- Quick and easy for customers to use  
- Easy to update prices, items, and availability  
- Scalable and ready for future features like full website or AI chatbot  

## Tech Stack

- Next.js (App Router)  
- Tailwind CSS  
- React functional components  
- Static JSON for menu data (easy to update)
